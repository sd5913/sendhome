# 送小鱼回家 — 白模关卡

这是一个不依赖图片素材、第三方库或后端的浏览器原型。关卡用几何体和文字标记，方便先验证移动、角色差异、机关和通关流程。它可以直接放在 GitHub Pages 上运行。

## 运行

在仓库根目录运行：

```powershell
uv run --no-project python -m http.server 8000
```

然后打开 <http://127.0.0.1:8000/game-whitebox/>。也可以直接打开 `index.html`；使用本地服务器更接近 GitHub Pages 的运行方式。

## 操作

- `A` / `D` 或方向键：移动当前角色
- `W` / `Space` / `↑`：跳跃
- 按住 `Shift` 并移动：冲刺，用于测试撞门
- `1`、`2`、`3`：切换鱼；`Tab`：依次切换
- `Esc`：暂停 / 继续
- 长按 `R`：重置本关；也可以点击重置按钮

## 白模内的测试点

从左向右依次测试：

1. 方块：重量大于 1.5 的鱼可以推动，A 鱼不能；箱子会被关着的门或关卡边界挡住，并显示阻挡原因。
2. 压力板和门：压力板需要总重量达到 4，C 鱼单独可以触发。让 C 留在压板上，再让另一条鱼推箱子通过门。有人通过门洞时门保持开启，离开后关闭。
3. 钥匙和门：任意鱼碰到钥匙后，钥匙门解锁。
4. 可撞门：冲刺撞击速度达到 500 px/s 时破门。
5. 检查点：A、B、C 三条鱼都进入终点范围后通关。
6. 鱼的碰撞：跳到另一条鱼上，观察“脚下支撑”；这是单向落脚面，离开鱼背后会重新下落。

鱼的重量同时作为压板重量和推箱力量；三种鱼的尺寸与相对速度沿用角色设定。白模里的门槛、速度单位和关卡距离是用于测试的初始参数，后续应由试玩反馈调整。

## 当前范围

- 单人控制三条鱼；未实现联网、菜单、多关卡、美术和音效。
- 玩家只能操控当前选中的鱼，其他鱼保持原位并受重力影响，也可以作为临时落脚平台。
- 所有游戏逻辑在浏览器 JavaScript 中运行。GitHub Pages 是静态托管，不能直接执行 Python；本原型因此采用原生 HTML Canvas 和 JavaScript，避免后端和部署依赖。
