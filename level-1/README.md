# LV1 · 基础移动教学

依据仓库 GDD `期末teamwork.docx` 与用户更新的第二版关卡蓝本搭建（蓝本原图不随代码上传）。GDD 中英文模板提示作为文档内容读取，关卡行为依据其中的实际设计条目实现。

在仓库根目录运行 `python3 -m http.server 8000`，打开 http://localhost:8000/level-1/ 。本关使用 ES 模块，需通过 HTTP 访问。

## 布局

一格为 36 像素，地图为 32×22 格。草图中的左侧 2×2、2×1、1×1 方块分别映射至鱼 C、B、A。

| 地形 | 格坐标 x, y | 宽×高（格） |
| --- | --- | --- |
| 起点 | 2, 16 | 11×1 |
| 三阶下行台阶 | 13,16 / 14,17 / 16,18 | 1×3 / 2×2 / 2×1 |
| 下层回落平台 | 13, 19 | 16×1 |
| 第一跳台 | 12, 13 | 4×1 |
| 第二跳台 | 19, 12 | 4×1 |
| 终点平台 | 26, 13 | 5×1 |
| 检查点 | 28, 10 | 3×3 |

地图坐标根据新版手绘格线近似还原。路线为起点 → 高三格的第一跳台 → 再高一格的第二跳台 → 低一格的终点平台。检查点从红色地面标记向上延伸三格，容纳三条鱼及叠站情况。下方长平台与左侧阶梯保留；失足后可向左回到起点再尝试，不能从下层直接跳到高处。

跳跃初速度由 650 调整为 600 px/s，重力维持 1500 px/s²；理论最大上升高度由约 3.91 格降至 3.33 格（约降低 15%）。三条鱼使用相同跳跃高度，保留各自横向速度。首跳需在平台左侧起跳，升高后向右落上平台；后两跳在边缘附近起跳即可。

## GDD 规则

- A：1×1 格、重 1、速度 2；B：2×1 格、重 2、速度 1.5；C：2×2 格、重 4、速度 1。
- A/D、方向键移动，W/空格/↑ 跳跃；1/2/3、Tab 切换；Esc 暂停；按住 R 0.7 秒重置。提供触屏按钮。
- LV1 仅教学移动与跳跃，约 30 秒为体验目标，不设置失败倒计时。没有冲刺、箱子、压板或门。
- 三条鱼须同时完整进入检查点并落地（或落在伙伴上）才完成关卡，完成数只增加一次。到达后仍可移动，离开检查点会实时减少计数。
- 越出地图下边缘时该鱼回到起点；暂停、失焦时停止操作。下层长平台提供练习路线。
- 目前为单机白模。美术接入、联机、后续四关尚未实现；不将 LV1 通关等同于全游戏通关。

## 验证

`node --test level-1/engine.test.mjs`

覆盖角色规格、三鱼经过两个跳台的完整路线（无需冲刺）、削弱后的跳跃高度、实时集合计数、单次结算、跌落复位、暂停、平台侧面及底部碰撞。客户端以 120 Hz 固定步长运行物理。
