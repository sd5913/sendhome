# LV1 · 基础移动教学

依据仓库 GDD `期末teamwork.docx` 与用户更新的第二版关卡蓝本搭建（蓝本原图不随代码上传）。GDD 中英文模板提示作为文档内容读取，关卡行为依据其中的实际设计条目实现。

在仓库根目录运行 `python3 -m http.server 8000`，打开 http://localhost:8000/level-1/ 。本关使用 ES 模块，需通过 HTTP 访问。

跳跃初速度由 650 调整为 600 px/s，重力维持 1500 px/s²；理论最大上升高度由约 3.91 格降至 3.33 格（约降低 15%）。三条鱼使用相同跳跃高度，保留各自横向速度。首跳需在平台左侧起跳，升高后向右落上平台；后两跳在边缘附近起跳即可。

## GDD 规则

- A：1×1 格、重 1、速度 2；B：2×1 格、重 2、速度 1.5；C：2×2 格、重 4、速度 1。
- A/D、方向键移动，W/空格/↑ 跳跃；1/2/3、Tab 或点击画面中的小鱼切换；Esc 暂停；按住 R 0.7 秒重置。提供触屏按钮。
- LV1 仅教学移动与跳跃，约 30 秒为体验目标，不设置失败倒计时。地编不放置箱子、压板或门；冲刺与所有机制规则均由共用引擎提供，未按关卡单独关闭。
- 三条鱼须同时进入检查点的检测框（有任意重叠面积即可）并落地（或落在伙伴上）才完成关卡，完成数只增加一次。到达后仍可移动，离开检测框会实时减少计数。
- 越出地图下边缘时该鱼回到起点；暂停、失焦时停止操作。下层长平台提供练习路线。
- 目前为单机白模。美术接入、联机、后续四关尚未实现；不将 LV1 通关等同于全游戏通关。

## 鱼之间的碰撞与负重

- 鱼的四边均参与碰撞；同层时，更重的鱼可以横向推走更轻的鱼，重量相同或更重则互相阻挡，需要跳过去。
- 推动判定比较“推力”和“阻力”：推力 = 自身重量² ÷（自身重量 + 背上乘客总重量）；阻力 = 目标鱼连同其背上乘客的总重量，推力严格大于阻力才能推动。
- 推动速度 = 正常移动速度 × 推力 ÷（推力 + 阻力），所以背上有鱼时会同时降低走路速度和推动速度。
- 数值示例：B 单独推 A 为 180 px/s（B 空身 270 px/s）；B 背着 A 时推力约 1.33，只能慢慢推 A（约 103 px/s），推不动 B 或 C；C 单独推 B 为 120 px/s，C 背着 A 推 B 约 89 px/s；A 推不动任何鱼。
- 站在鱼背上会跟随其水平移动与跳跃，支持三层叠站。跳离或走出鱼背后解除跟随。
- 承载者速度 = 原移动速度 × 自身重量 /（自身重量 + 背上所有鱼的总重量）。跳跃初速度不因负重改变。
- B 背 A：270 × 2/3 = 180 px/s；C 背 A：180 × 4/5 = 144 px/s；A 背 C：360 × 1/5 = 72 px/s。
- 三层叠站时累计上方所有乘客重量；乘客撞墙或顶到平台时限制整组移动，防止穿模。
- 右侧显示当前控制角色的背上总重量和移动速度比例。检查点宽三格，三鱼需要合理叠站才能同时进入。
