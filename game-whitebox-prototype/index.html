送小鱼回家｜白模测试关

从左向右逐项测试角色、箱子、压板、钥匙门、撞门和终点。当前版本是功能白模，不含最终美术。

测试顺序

  1. 用 B 或 C 推动方块，A 推不动；关闭的门会挡住箱子。
  2. 让 C 踩住压板开门，再让另一条鱼继续推箱子。
  3. 任意鱼碰钥匙，钥匙门解锁。
  4. 按住 Shift 加速撞击最后一扇门。
  5. 分别把三条鱼带进终点范围。
  6. 推不动或挡路时可以跳过；也可跳到另一条鱼背上。
